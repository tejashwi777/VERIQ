# VERIQ – Quality Assurance Data Studio

VERIQ is a web-based QA utility built using Python and Flask. It helps testers generate sample customer records and perform basic data validation.

### Features
- Generate 10, 25, 50, or 100 sample customer records.
- Validate email addresses and Nepal-style phone numbers.
- Detect duplicate email addresses.
- View valid and invalid records.
- Search and filter generated data.
- Copy individual records.
- Export test data as CSV.

### Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

### Purpose
This project was created to practice software quality assurance concepts, data validation, and test data management through a simple interactive web application.
